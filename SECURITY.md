# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.x.x   | :white_check_mark: |
| < 7.0   | :x:                |

## Responsible Disclosure & Scope

**Reflectra** is designed solely for authorized security assessment, penetration testing, and vulnerability research. Users must obtain explicit written authorization before scanning any target infrastructure.

If you believe you have discovered a security vulnerability within Reflectra itself (such as unhandled arbitrary code execution during parsing or unintended privilege boundary crossing), please report it responsibly.

### Reporting a Vulnerability

1. **Do NOT** open a public issue on GitHub.
2. Email your findings directly to `pratik.khairnar.sec@gmail.com` with:
   - A detailed description of the flaw.
   - Steps or environment needed to reproduce.
   - Any proposed remediation or patches.
3. You will receive an acknowledgment within 48-72 hours.
4. We coordinate a public disclosure timeline once a fix has been verified and released.
